# Study Scoop

Free weekly practice for our 3rd grade class: spelling, vocabulary, multiplication, homework, and the class newsletter.

No sign-in and nothing saved. Open the link and practice.

## Adding a new week

1. Add the newsletter photo to `images/newsletters/` named by that Monday's date (for example `2026-10-26.jpg`).
2. Copy last week's file in `data/` to a new file with the same date name and update the words, tests, and homework.
3. Add the week to the top of `data/weeks.json` and set it as `current`.

Vocabulary definitions are always copied exactly as written on the class vocabulary sheet.

See `CLAUDE.md` for the full design and data format.
