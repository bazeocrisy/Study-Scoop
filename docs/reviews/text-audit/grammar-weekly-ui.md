# Study Scoop: spelling, grammar and punctuation audit (weekly data, reading, tests, homework, UI, labs, game)

Auditor: independent grammar auditor. Read-only; no repository files changed. Standard: American English, for an 8-year-old reader (parent text for parents).
Date: 2026-11-12. Method: every string value pulled from the in-scope JSON files with a Node script (about 4,000 strings), then deduplicated and read by hand. Quoted UI strings and text nodes pulled from index.html, js/*.js, js/views/*.js, the student-facing generators in js/lib (activities, skills, reading, fractions), labs/*.html and games/*.html. Automatic checks: doubled words, a/an, British spellings, double spaces, space before punctuation, "1 + plural noun", unmatched quotes and parentheses, and sentences starting in lowercase.

"Teacher source" = copied word for word from the class newsletter or vocabulary sheet. Do not change these silently. The fix offered is a Study Scoop "In other words" note shown next to the teacher's wording.

## Observations outside grammar (for the lead)

1. **Privacy (CLAUDE.md, repository is public):** games/multiplication-mastery-8.html names a child ("[child name] #21", "Hi, [child name]!", "Erase ALL of [child name]’s scores", CSV file "[child-name]-scores.csv"). It also has photo alt text "[child name] II in his GA cap and jersey on the baseball field" / "…practicing his baseball swing in the batting cage", which suggests photos of an identifiable child are embedded. It also saves scores in the browser ("Scores are saved only in this browser on this device"), which goes beyond the single approved persistent store (Lesson 7-1, D29). This needs Product Owner review.
2. The homework/2026-11-09.json `about` promises "Save my work to keep your answers", and the 11-02 `about` says "Nothing is … saved after you close the page." Both are accurate (the button prints), but the wording reads as if it contradicts itself. Clearer: "Your answers are not saved. Print or save as PDF to keep them."
3. Dated text that is now in the past is still shown as current advice: js/views/math.js:111 and :307 ("For the class test on Tuesday, Nov 3 …"); data/tests/2026-10-26.json `math.note`.
