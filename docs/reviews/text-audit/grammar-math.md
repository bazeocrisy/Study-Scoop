# Spelling / grammar / punctuation / clarity audit: Math content (Chapters 5, 6, 7)

Scope: data/lessons/5-*.json, 6-*.json, 7-*.json, data/lessons/index.json, data/practice/{area,math,math-words}.json, data/chapters/7.json, js/lib/partition-journey.js, js/views/partition-journey.js (child-facing strings only).
Method: node extraction of every string with its JSON path (17,853 prose strings), deduplicated by normalizing digits and fraction words (5,012 templates), automatic checks (doubled words, a/an, "1 + plural" and "plural number + singular", verb agreement after 1, British spellings, double spaces, trailing spaces, brackets, quote punctuation, term counts), then a full manual read of every deduplicated template. Math correctness was not judged.

Automatic checks with no findings: British spellings (labelled, colour, practise, centre, metre, grey, -ise), doubled words, a/an errors, double spaces, unmatched brackets in data. Every hit in the code files was markup.

Severity: Critical = wrong or misleading meaning. Major = clear grammar or spelling error, or a confusing instruction. Minor = style, consistency or wordiness.
"(xN)" = number of strings that use the same template. "Hand-edited" = no generator in scripts/author contains the phrase.
